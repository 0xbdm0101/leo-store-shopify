# 功能需求规范：Ajax 侧边滑出购物车抽屉（含免运费进度条与加购推荐）

**功能目录**：`specs/002-cart-drawer`

**创建时间**：2026-07-30

**状态**：草案 (Draft)

**需求来源**：用户描述：“实现侧边滑出式购物车抽屉功能，带免运费进度条和加购推荐”

---

## 用户场景与测试 *(必填)*

### 用户故事 1 - 侧边滑出 Ajax 购物车抽屉 (优先级: P1 - MVP核心)

作为一名购物者，当我点击任何商品页上的“加入购物车”或点击页头购物车图标时，我希望购物车抽屉能从屏幕右侧平滑滑出，以便我能立即查看和管理购物车商品，而无需跳转离开当前页面。

**优先级理由**：核心购物体验。减少购物车放弃率，提升页面留存率并提供即时视觉反馈。

**独立测试方法**：点击“加入购物车”或页头购物车图标。抽屉平滑滑出，正确显示商品列表、单价、数量调节按钮与小计金额，支持修改数量或删除商品，且购物车图标徽章和金额即时刷新。

**验收场景**：

1. **假设** 购物者位于任何页面，**当** 他们点击页头购物车图标或“加入购物车”按钮时，**那么** 购物车抽屉平滑从屏幕右侧滑出，背景呈现半透明遮罩。
2. **假设** 购物车抽屉已打开且包含商品，**当** 购物者点击数量 `+` / `-` 按钮或“删除”链接时，**那么** 商品数量与小计通过 Ajax 实时更新，无需刷新页面。
3. **假设** 购物车抽屉已打开，**当** 购物者点击关闭 `X` 按钮、按 `Escape` 键或点击背景蒙层时，**那么** 购物车抽屉平滑收回关闭。

---

### 用户故事 2 - 动态免运费进度条 (优先级: P2 - 提升客单价)

作为一名购物车中有商品的购物者，我希望能看到一个直观的进度条提示我距离包邮还差多少金额（例如：“再凑 $15.00 即可享受免运费！”），从而激励我加购更多商品以达到包邮门槛。

**优先级理由**：直接提升客单价 (AOV) 的神器，游戏化购物体验。

**独立测试方法**：在主题编辑器中设置免运费门槛（如 $100）。当购物车总额低于 $100 时，进度条按比例填充并提示剩余差额；当达到或超过 $100 时，进度条变为 100% 并展示祝贺文字（“恭喜！您已解锁免运费福利！”）。

**验收场景**：

1. **假设** 购物车金额低于设置门槛（例如 $75 / $100），**当** 抽屉打开或金额变动时，**那么** 进度条显示 75% 进度，并提示：“再凑 $25.00 即可解锁免运费！”。
2. **假设** 购物车金额达到或超过门槛（例如 $110 / $100），**当** 抽屉刷新时，**那么** 进度条显示 100% 满格，呈现绿色成功状态并提示：“您已解锁免运费福利！”。

---

### 用户故事 3 - 抽屉内加购/交叉推荐 (优先级: P3 - 关联销售)

作为查看购物车抽屉的购物者，我希望在抽屉底部看到推荐的相关商品（如配饰、热门加购品），并带有“一键加购”按钮，以便我能方便地将相关商品加入订单。

**优先级理由**：增加交叉销售机会，帮助购物者更快凑满包邮门槛。

**独立测试方法**：在主题编辑器中配置推荐集合。抽屉底部展示最多 3 款推荐商品，点击“一键加购”后，该变体立即加入购物车，抽屉与进度条实时更新。

**验收场景**：

1. **假设** 购物车抽屉已打开，**当** 存在推荐商品时，**那么** 抽屉底部展示“猜你喜欢”卡片列表，包含商品图片、标题、价格和“一键加购”按钮。
2. **假设** 购物者点击推荐卡片上的“加购”按钮，**那么** 该商品通过 Ajax 迅速加入购物车，抽屉和免运费进度条自动刷新。

---

### 边界情况 (Edge Cases)

- **空购物车状态**：当购物车中无商品时，抽屉展示友好的空状态提示和“继续购物”按钮，并隐藏结算按钮。
- **库存上限限制**：当加购数量超过当前库存时，系统展示提示信息（“已达到最大可用库存”）。
- **多语言与多币种**：所有金额统一使用 `{{ cart.total_price | money }}` 过滤器，所有文字标签统一使用 `{{ 'cart.drawer.*' | t }}` 国际化键值。

## 功能需求 (Requirements)

### 功能需求清单

- **FR-001**：主题必须提供可配置的 `sections/cart-drawer.liquid` 模块，支持在 Shopify 主题编辑器中进行可视化设置。
- **FR-002**：系统必须渲染购物车商品行，包含商品主图、标题、变体属性、单价、数量选择器与删除按钮。
- **FR-003**：系统必须通过 Shopify Cart Ajax API (`/cart/add.js`, `/cart/change.js`, `/cart.js`) 异步更新购物车状态，拒绝全页刷新。
- **FR-004**：主题必须允许商家在 `sections/cart-drawer.liquid` 的 Schema 设置中配置“免运费目标门槛金额”。
- **FR-005**：系统必须动态计算免运费剩余差额：`Max(0, 门槛金额 - 购物车总额)`，并配合当前店铺货币进行格式化。
- **FR-006**：主题必须允许商家在 Schema 设置中选择一个“推荐商品集合 (Collection)”。
- **FR-007**：推荐列表中必须自动过滤掉当前购物车中已存在的商品。
- **FR-008**：系统必须展示小计金额、运费/税费说明以及突出的“去结算”按钮（直接跳转至 `/checkout`）。
- **FR-009**：所有前端展示文字必须使用翻译键（如 `{{ 'cart.drawer.title' | t }}`），并在 `locales/en.default.json` 中提供默认文本。
- **FR-010**：样式与脚本必须封装在 `sections/cart-drawer.liquid` 内，使用 `{% stylesheet %}` 和 `{% javascript %}` 标签隔离。

### 核心数据实体 (Key Entities)

- **购物车抽屉模块 (Cart Drawer Section)**：代表抽屉容器、配置项（门槛、推荐集合、颜色）及背景蒙层。
- **购物车商品行 (Cart Line Item)**：代表加入购物车的商品变体，包含变体 ID、数量、行小计、折扣及属性。
- **免运费进度状态 (Free Shipping State)**：代表目标金额、当前总额、剩余差额、百分比与解锁状态。
- **推荐商品卡片 (Upsell Product Item)**：代表抽屉底部的推荐商品，包含变体 ID、标题、缩略图、价格与加购状态。

## 成功衡量标准 (Success Criteria)

- **SC-001**：用户点击“加入购物车”或购物车图标后，抽屉在 150ms 内平滑滑出。
- **SC-002**：所有 Ajax 变更（修改数量、删除、加购推荐）在 400ms 内完成 UI 重新渲染。
- **SC-003**：整个购物过程（打开 -> 修改商品 -> 加购推荐 -> 去结算）零页面刷新。
- **SC-004**：100% 前端文本支持国际化多语言翻译。

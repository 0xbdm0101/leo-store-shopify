# 快速验证指南：Ajax 侧边滑出购物车抽屉

## 验证测试场景

### 场景 1：抽屉开关与蒙层测试
1. 在浏览器或预览链接中打开主题。
2. 点击页头购物车图标。
3. **验证**：
   - 购物车抽屉从屏幕右侧平滑滑出。
   - 抽屉后方显示半透明背景蒙层。
   - 抽屉展开时页面禁止背景滚动。
4. 按 `Escape` 键或点击背景蒙层。
   - **验证**：购物车抽屉平滑收回关闭。

### 场景 2：Ajax 商品数量修改与删除
1. 打开包含至少 1 件商品的购物车抽屉。
2. 点击商品行上的 `+` 按钮。
   - **验证**：数量增加，行小计与总金额即时更新，无需重载页面。
3. 点击 `-` 按钮直到数量变为 0，或点击“删除”按钮。
   - **验证**：商品平滑从抽屉中移除；若购物车变为空，显示空购物车提示信息。

### 场景 3：免运费进度条动态测试
1. 在主题编辑器中将 `cart-drawer` 的免运费目标门槛设置为 `$100.00`。
2. 加购一件价格为 `$40.00` 的商品。
   - **验证**：进度条显示 40% 填充；文案显示：“再凑 $60.00 即可享受免运费！”。
3. 将商品数量修改为 3 件（总价 `$120.00`）。
   - **验证**：进度条平滑动画至 100% 满格；文案变为绿色祝贺：“您已解锁免运费福利！”。

### 场景 4：推荐商品 1-Click 一键加购
1. 在主题编辑器中为抽屉配置推荐商品集合。
2. 打开购物车抽屉。
   - **验证**：抽屉底部显示推荐商品卡片。
3. 点击推荐卡片上的“一键加购”按钮。
   - **验证**：商品异步加入购物车，抽屉与免运费进度条即时刷新，已加购的商品自动从推荐列表中移除。

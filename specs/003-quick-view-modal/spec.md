# 功能需求规范：商品快速预览弹窗 (Quick View Modal)

**功能目录**：`specs/003-quick-view-modal`

**创建时间**：2026-08-06

**状态**：草案 (Draft)

**需求来源**：用户描述：“实现商品快速预览弹窗功能 (Quick View Modal)：支持商品列表页 Hover 触发弹窗、多图缩略图切换、变体选择与价格联动、一键加购联动购物车抽屉以及查看完整详情入口”

---

## 用户场景与测试 *(必填)*

### 用户故事 1 - 列表页 Quick View 悬浮触发与 Modal 弹窗渲染 (优先级: P1 - MVP核心)

作为一名购物者，在浏览商品列表页（Collection 页或首页商品展示网格）时，当我将鼠标悬停在某个商品卡片上并点击“Quick View / 快速预览”按钮时，我希望能在当前页面弹出一个商品快速预览 Modal 窗，而无需跳转离开当前列表页。

**优先级理由**：减少跳转等待时间，大幅提升购物者的列表页浏览效率与商品发现体验。

**独立测试方法**：在商品列表页鼠标悬停商品卡片，显示“Quick View”按钮；点击后，通过 Shopify Section Rendering API (`?section_id=quick-view-modal`) 动态加载弹窗，呈现蒙层背景与居中弹窗，点击背景蒙层或关闭按钮可平滑关闭。

**验收场景**：

1. **假设** 购物者位于商品列表页，**当** 鼠标悬停在商品卡片上时，**那么** 卡片图片下方/中央平滑淡入“Quick View / 快速预览”按钮。
2. **假设** 购物者点击“Quick View”按钮，**那么** 页面显示半透明蒙层，中心呈现 Modal 视窗，通过 Section Rendering API 加载目标商品的完整快速预览内容。
3. **假设** 弹窗已打开，**当** 购物者点击右上角关闭 `X` 按钮、按 `Escape` 键或点击背景蒙层时，**那么** 弹窗收回关闭，页面恢复正常滚动。

---

### 用户故事 2 - 缩略图切换与多变体选项联动 (优先级: P2 - 变体选择)

作为一名在快速预览弹窗中查看商品的购物者，我希望能够点击缩略图切换展示大图，并选择不同的颜色、尺寸等变体，以便我能直观看到对应变体的图片、价格与库存状态。

**优先级理由**：变体信息与图片联动是服装、鞋帽及多规格商品促成购买决策的关键。

**独立测试方法**：在弹窗中点击下方缩略图，主图随之切换；点击切换变体选项（如颜色从黑色切到红色），主图自动更新为对应变体的图片，价格显示该变体的价格，若该变体无货，购买按钮变为“已售罄”禁用状态。

**验收场景**：

1. **假设** 商品包含多张缩略图，**当** 购物者点击某张缩略图时，**那么** 主图平滑切换为对应大图。
2. **假设** 购物者选择不同的变体组合（如“颜色：红色”与“尺寸：L”），**那么** 价格、原价/折后价、库存状态（有货/售罄）以及对应的变体主图实时刷新。

---

### 用户故事 3 - 一键加购与购物车抽屉 (Cart Drawer) 联动 (优先级: P3 - 链路闭环)

作为一名在快速预览弹窗中决定购买商品的购物者，我希望点击“加入购物车”后，该变体能瞬间加入购物车，并**自动平滑打开上一次开发好的侧边购物车抽屉 (Cart Drawer)**，以便我能无缝确认订单与结算。

**优先级理由**：闭环购物路径。将 Quick View 弹窗与 Cart Drawer 抽屉无缝串联，形成极佳的无刷新加购流。

**独立测试方法**：在 Quick View 弹窗中选择变体与数量，点击“加入购物车”。弹窗自动关闭或保持，同时侧边 Ajax Cart Drawer 平滑滑出，免运费进度条自动更新。

**验收场景**：

1. **假设** 购物者在 Quick View 弹窗中点击“加入购物车”，**那么** 选中的商品变体通过 Ajax 加入购物车，Quick View 弹窗关闭，侧边 Cart Drawer 自动滑出并呈现最新商品与小计。
2. **假设** 购物者想了解更多参数，**当** 点击弹窗底部的“查看完整详情 (View Full Details)”链接时，**那么** 跳转到该商品的独立 PDP 页面 (`/products/<handle>`)。

---

### 边界情况 (Edge Cases)

- **单变体商品**：若商品只有默认单一变体，不展示变体下拉框/单选块，直接展示默认价格与加购按钮。
- **无货/售罄变体**：选中售罄变体时，加购按钮变灰显示 `cart.drawer.sold_out`（已售罄）并禁止点击。
- **网络延迟或失败**：请求 Section Rendering API 失败时，提示“无法加载商品预览”，并提供直接跳转到商品页的备用链接。

---

## 功能需求 (Requirements)

### 功能需求清单

- **FR-001**：主题必须提供可独立配置的 `sections/quick-view-modal.liquid` 模块，支持 Section Rendering API 调用。
- **FR-002**：商品列表页（`sections/collection.liquid` 等）的商品卡片必须包含带 `data-handle="{{ product.handle }}"` 的“Quick View”触发按钮。
- **FR-003**：系统必须通过 API 请求 `/products/<handle>?section_id=quick-view-modal` 获取服务端渲染好的 Modal 视图 HTML。
- **FR-004**：Quick View 弹窗必须包含商品多图展示区（主图 + 缩略图切换）。
- **FR-005**：Quick View 弹窗必须渲染变体选择器，变体切换时通过原原生 JS 联动更新变体图片、价格、原价与库存状态。
- **FR-006**：Quick View 弹窗必须包含“加入购物车”表单，提交时通过 Ajax 加购并触发全局 `CartDrawer` 打开事件。
- **FR-007**：Quick View 弹窗必须包含指向商品详情页的“查看完整详情 (View Full Details)”跳转链接。
- **FR-008**：所有展示文本必须使用 `{{ 'products.product.quick_view' | t }}` 等国际化翻译键，并在 `locales/en.default.json` 提供默认词条。
- **FR-009**：样式与 JavaScript 控制器必须封装在 `sections/quick-view-modal.liquid` 内部，使用 `{% stylesheet %}` 和 `{% javascript %}` 隔离。
- **FR-010**：必须满足 WCAG 2.1 AA 无障碍规范（支持 `Escape` 键退出、蒙层点击退出与键盘 Tab 键焦点锁定）。

### 核心数据实体 (Key Entities)

- **Quick View Modal Section**：弹窗外层容器、背景蒙层、动态加载面板。
- **Quick View Product State**：包含商品 Handle、当前选中的变体对象（ID、价格、可售状态、图片 URL）、商品变体数组 JSON。

---

## 成功衡量标准 (Success Criteria)

- **SC-001**：点击“Quick View”按钮后，弹窗在 250ms 内完成异步请求与平滑渲染呈现。
- **SC-002**：切换变体选项时，价格与主图在 50ms 内瞬间响应完成更新。
- **SC-003**：在 Quick View 弹窗内加购后，直接触发侧边 Cart Drawer 打开，全过程 0 页面刷新。
- **SC-004**：100% 前端文本支持国际化多语言翻译。

---

## 假设条件 (Assumptions)

- 店铺环境支持 Shopify Theme 2.0 Section Rendering API。
- 侧边购物车抽屉（`CartDrawer` 控制器）已就绪并可响应全局加购事件。

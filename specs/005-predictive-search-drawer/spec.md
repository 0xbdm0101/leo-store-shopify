## 概述与业务目标

为商城访客提供极速、苹果风格的 **智能实时搜索抽屉**。用户在顶部 Header 点击搜索图标（🔍）时，侧滑打开高质感毛玻璃搜索抽屉。用户打字时，系统基于 Shopify Predictive Search API (`/search/suggest.json`) 进行 300ms 智能防抖实时模糊匹配，展示带高精缩略图、标题、品牌、动态价格及促销标签的商品列表与搜索建议。输入框为空时，优先展示热门搜索词（Trending Searches）。所有 UI 遵循宪法 Principle VI Apple Sports 极简美学，并支持 100% 全动态多语言（i18n）跟随切换。

---

## 用户场景与主要流程

### 主场景 1：触发搜索与热门搜索词推荐
- **当** 访客在商城任意页面点击 Header 顶部右侧的 🔍 搜索图标时，
- **那么** 右侧平滑滑出毛玻璃遮罩搜索抽屉 (`#SearchDrawer`)，且搜索输入框自动聚焦。
- **并且** 当搜索框内容为空时，展示“热门搜索”标签（`🏸 羽球拍`、`👟 运动鞋`、`🎽 比赛服`、`🛡️ 护具`）。
- **当** 用户点击任意热门搜索词标签时，关键词自动填入搜索框并立即发起查询。

### 主场景 2：实时模糊匹配与商品卡片预览
- **当** 用户在搜索框中输入关键词（如 "Yonex"、"鞋"、"羽球"）时，
- **那么** 系统等待 300ms 防抖间隔后，呈现骨架屏 Loading 加载状态。
- **并且** 实时渲染匹配的商品列表，包含：
  - 商品缩略图（含悬停微放大动画）
  - 商品标题与品牌 Vendor
  - 格式化当前售价与划线原价
  - “加入购物车”或“快速预览”快捷操作按钮
- **并且** 呈现分类与搜索建议列表。

### 主场景 3：无匹配友好提示与键盘交互
- **当** 用户搜索无匹配结果的词汇（如 "xyz123"）时，
- **那么** 呈现亲切的“未匹配到与 'xyz123' 相关的装备”提示界面，并推荐热门分类。
- **当** 用户按下 `ESC` 键或点击抽屉遮罩时，抽屉平滑关闭。
- **当** 用户按下 `Enter` 键时，跳转至完整搜索结果页 `/search?q=...`。

## 功能需求清单

### 1. Header 顶部图标集成
- 在 `sections/header.liquid` 顶部右侧工具栏中新增 🔍 搜索图标按钮，绑定 `data-action="open-search-drawer"` 触发事件。

### 2. 预测搜索 API 与防抖机制
- 调用 Shopify 官方 Predictive Search API：`/search/suggest.json?q={query}&resources[type]=product,query&resources[limit]=6`。
- 实现 300ms JavaScript 防抖定时器，避免频繁发起 HTTP 请求。
- 请求过程中呈现脉冲骨架屏（Skeleton Loader）。

### 3. 动态商品卡片与快捷操作
- 使用独立的商品渲染结构，支持点击直接调用 `ThemeCartUtils.submitAddToCart` 快捷加入购物车并刷新侧边购物车。

### 4. 全站多语言国际化 (i18n)
- 将抽屉标题、输入框 Placeholder、热门搜索标题、无结果提示语、查看全部按钮等词条全部写入 `zh-CN.json`、`en.default.json` 和 `fr.json`。

## 验收与成功标准

1. **低于 100ms 感知响应**: 搜索结果加载顺畅，带骨架屏过渡，零页面抖动。
2. **零横向溢出 (0 Overflow)**: 严格遵循 `max-width: 100%; overflow-x: hidden`，无触摸板右滑空白。
3. **100% 动态语言跟随**: 切换语言时，搜索抽屉内所有文案 100% 实时同步。

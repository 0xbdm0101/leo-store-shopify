# 快速验证指南：005-predictive-search-drawer

## 验证前准备
- 启动 Shopify Theme 开发服务器或打开预览链接。

## 验证步骤
1. **点击 Header 🔍 搜索图标**: 校验毛玻璃搜索抽屉平滑滑出，输入框自动获得焦点。
2. **测试热门搜索词**: 点击热门标签 `🏸 羽球拍`，校验搜索框自动填入并实时发起匹配。
3. **输入关键词 "鞋"**: 校验 300ms 防抖效果、骨架屏 Loading 加载以及带有商品缩略图、标题、品牌的商品卡片呈现。
4. **多语言切换测试**: 切换语言，校验搜索抽屉内所有标题、Placeholder、提示语 100% 动态同步切换。
5. **语法与规范校验**: 运行 `shopify theme check`，确保 0 Error 通过。
